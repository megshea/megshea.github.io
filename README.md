# Megan Armbrust Portfolio — Readable Version

This version is the same site, but the code has been cleaned up and formatted so it is much easier to edit directly in GitHub.

## Where to edit things

### Homepage
`index.html`

The six floating homepage images are labeled:
- p1
- p2
- p3
- p4
- p5
- p6

### Project list
`js/projects.js`

Each project is its own clearly separated block.

### Homepage positions and sizes
`css/style.css`

Search for:
- `.p1`
- `.p2`
- `.p3`
- `.p4`
- `.p5`
- `.p6`

### Images
Upload your real image files into:
`images/`

Then replace paths like:
`images/p1.svg`

with something like:
`images/recipe-roulette.jpg`

### Interaction
`js/script.js`

This controls:
- project cards
- homepage cursor movement

You probably do not need to edit this file often.

## Uploading
Upload all files and folders inside this package into the root of the `megshea.github.io` repository and replace the existing versions.
